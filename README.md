# AppleCompass

A desktop clone of the Apple iOS Compass app, built with QML and C++ using the Qt framework.

This project aims to replicate the functionality and design of the iOS Compass app, providing a familiar user experience for desktop users.

## Getting Started

### Prerequisites

- [Qt 6.x.y](https://www.qt.io/download)

### Build & Run

1. Install Qt 6.x.y (Qt 6.2 or newer recommended).
2. Open `AppleCompass.pro` in Qt Creator.
3. Build and run the project.

## Project Structure

- `Qml/` – QML UI files
- `Source/` – C++ backend source code
- `Resources/` – Fonts and other assets
- `AppleCompass.pro` – Qt project file
